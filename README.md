# Bastion

A task management REST API built with Django REST Framework,
designed with a security-first approach: JWT auth, rate limiting,
input validation, and audit logging.

## Stack
- Python / Django / DRF
- PostgreSQL
- Docker

## Status
🚧 In development

## Setup
\`\`\`bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
\`\`\`
